# STM32 超声波避障小车（STM32-Ultrasonic-Car）

基于 **STM32F103C8** 的循迹小车，Keil MDK 工程。工程在开源循迹代码的基础上使用**双路 HC-SR04 超声波**进行障碍检测与避让。

## 功能

- 五路灰度传感器循迹（加权误差 + PID 速度环 / 转向环）
- MPU6050 陀螺仪辅助航向与误差融合
- 编码器测速与里程累计
- 双路 HC-SR04 超声波测距，按左右距离差判断障碍方位并执行绕行动作
- OLED 菜单显示，按键翻页

## 硬件接线

| 功能 | 引脚 |
|---|---|
| 灰度传感器 L2 / L1 / M / R1 / R2 | PA4、PA5、PA12、PB0、PB1 |
| 编码器（TIM3 / TIM4） | PA6 / PA7、PB6 / PB7 |
| 电机 PWM | PA8（TIM1_CH1）、PA11（TIM1_CH4） |
| 电机方向 | PB12、PB13、PB14、PB15 |
| MPU6050（软件 I2C） | PB3（SDA）、PB4（SCL） |
| OLED（软件 I2C） | PB9（SDA）、PB8（SCL） |
| 按键 | PA0、PA1 |
| 超声波 1（Trig / Echo） | PA3 / PA2 |
| 超声波 2（Trig / Echo） | PB10 / PB11（原蓝牙串口口） |

> 第二路超声波占用原 USART3 的 PB10 / PB11，因此**蓝牙（HC-06）功能已停用**，`User/main.c` 中的 `Serial_Init()` 已注释。

## 目录结构

```
Hardware/        外设驱动（电机、编码器、OLED、MPU6050、灰度、按键、超声波等）
Control/         控制逻辑（巡线误差、PID、元素/避障、菜单）
System/          延时、TIM2 定时调度、公共头文件
User/            main.c、中断服务、模块测试代码
Start/           CMSIS 与启动文件
Library/         STM32F10x 标准外设库
Project.uvprojx  Keil MDK 工程文件
```

## 编译与烧录

1. 使用 Keil MDK 5 打开 `Project.uvprojx`；
2. 目标芯片为 STM32F103C8；
3. 编译后通过 ST-Link 或串口下载。

## 注意事项

- 当前超声波代码的高电平计数上限为 1500，实际可测距离约 **25 cm**；
- 超声波 1 的 Echo 接在 PA2，该引脚不耐 5V，建议加分压电路或让模块使用 3.3V 供电；
- 第二路超声波与蓝牙共用同一接口，两者不能同时使用；
- 两路超声波应并排朝前安装，左右距离差用于判断障碍方位。
