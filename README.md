# STM32 超声波循迹避障小车

基于 **STM32F103C8T6** 的双路超声波循迹避障小车，Keil MDK 工程，用于《重走古丝路·自动循迹避障小车》比赛。

- 主控：STM32F103C8T6，72 MHz，标准外设库
- 循迹：五路灰度（数字量）+ MPU6050 陀螺互补融合
- 驱动：TB6612，双 N20 减速电机带霍尔编码器闭环
- 避障：两路 HC-SR04 判侧，绕行后自动回线
- 人机：0.96 寸 OLED 四页菜单 + 两个按键

配套文档：《代码整改说明（STM32-Ultrasonic-Car）.docx》（在上一级目录），含设计取舍、硬件风险清单与得分点分析。

> **OLED 翻页顺序（全文都按这个）**：**开机页 → 第 1 页 → 第 2 页 → 第 3 页 → 第 4 页 → 回到开机页**
> 按 **PA1 往下翻**、**PA0 往回翻**。各页内容：开机页 `READY` ｜ 第 1 页 左右轮速度与 PWM ｜ 第 2 页 偏差与避障状态 ｜ 第 3 页 里程 / 航向 / 两路超声距离 ｜ 第 4 页 距离差 / 无回波计数 / 故障位 / 终点状态

## 一、硬件接线

| 功能 | 引脚 | 说明 |
|---|---|---|
| 灰度 L2 / L1 / M / R1 / R2 | PA4、PA5、PA12、PB0、PB1 | 数字量，电位器定阈值；**均为非 5 V 容忍脚**，模块建议 3.3 V 供电 |
| 编码器（TIM3 / TIM4） | PA6 / PA7、PB6 / PB7 | 编码器模式 TI12，四倍频 |
| 电机 PWM | PA8（TIM1_CH1）、PA11（TIM1_CH4） | 10 kHz |
| 电机方向 | PB12、PB13（左）、PB14、PB15（右） | TB6612 的 AIN/BIN |
| MPU6050（软件 I2C） | PB3（SDA）、PB4（SCL） | 初始化时关闭 JTAG，保留 SWD |
| OLED（软件 I2C） | PB8（SCL）、PB9（SDA） | — |
| 按键 | PA0、PA1 | 上拉输入，翻页 |
| **超声波 1**（Trig / Echo） | **PA3 / PA2** | PA2 非 5 V 容忍，建议模块供 3.3 V 或分压 |
| **超声波 2**（Trig / Echo） | **PB10 / PB11** | 借用原蓝牙座（USART3），两脚均为 5 V 容忍 |
| 控制时基 | TIM2，10 ms | — |

> 板上原生只有一个 HC-SR04 座，2 号探头需另购，从原蓝牙座取信号（4 根杜邦线，接法见第六节）。
> 第二路占用原蓝牙串口，因此 `Serial_Init()` 保持注释，串口调试不可用。

## 二、控制结构

时基固定 **10 ms**（100 Hz）。中断里只做控制计算，其余全部搬到主循环：

| 任务 | 周期 | 位置 |
|---|---|---|
| 读陀螺（软件 I2C，连续读 2 字节） | 100 Hz，与节拍同步 | 主循环 |
| 超声波测距（两路交替，非阻塞状态机） | 30 ms / 路，单路约 60 ms 刷新 | 主循环 |
| 控制计算（误差 → 转向 → 差速 → 速度环） | 10 ms | TIM2 中断 |
| OLED 刷新 | 5 Hz，按键时立即重绘 | 主循环 |

串级结构：灰度偏差（与陀螺互补融合）→ 转向环 PD → 差速系数 → 左右轮目标速度 → 速度环 PID → PWM。

速度单位是"编码器脉冲 / 10 ms"：**100 ≈ 1.55 m/s**（65 mm 轮、1:30 减速、11 线编码器）。

## 三、三个关键设计

**1. 测距：DWT 计时 + 非阻塞状态机。**
按回波高电平的**真实微秒数**换算距离（0.01715 cm/µs），量程约 3.4 m（传感器标称 4 m，代码按"等上升沿 20 ms"截断）。不用"数循环次数"的写法——那种写法每次循环实际 1.2~1.5 µs 却按 1 µs 计，误差 20%~50%，而且 1500 计数的上限会把量程截断在 25.5 cm。

测距拆成"触发 → 等上升沿（≤20 ms）→ 量高电平（≤30 ms）"三段，主循环每轮只推进一点，**不再死等**。空场等不到回波也只占状态机，不堵 CPU，陀螺才能稳定跑 100 Hz。

**2. 避障是五步状态机，每步都有超时。**

```
空闲 → 80 cm 减速（降到 45）→ 45 cm 连续 6 拍确认 → 判侧（左近右绕 / 右近左绕）
     → 外转 60° → 直行 380 mm（侧移约 33 cm）→ 回转 55° → 带偏置找线 → 回到循迹
```

单步超时 2.5 s，整体超时 9 s；超时停车等人工，不会原地转圈。

**45 cm 是标称值，不是实际转向点。** 从 dmin 掉到 45 到电机真正反向，中间隔着一次刷新（单路最长 60 ms）和 6 拍确认（60 ms），接近段按 45（0.7 m/s）折算约 8.4 cm，所以实际在 **36 cm 左右**才开始打方向；再算 60° 外转时的前角前扫，最小间距约 32 cm。

**3. 终点判定 + 满占空比制动。**

里程 **4 m** 之前的全黑一律忽略（起点线也在其中）；之后只有与上次全黑间隔 ≥800 mm 的全黑，连续 2 拍确认才判为终点。最后 3.5 m 巡航自动降到 45（`STOP_APPROACH_SPEED`）——20 mm 的线在 1.55 m/s 下只停留 12.9 ms（1.3 个控制拍），降到 45 后是 28.6 ms（2.9 拍），连续 2 拍确认才有余量；只降到 60 的话窗口只有 21.6 ms（0.16 拍余量），车头偏 5° 就会漏判。避障与找线期间不参与判定，避免路过的黑区把计数带偏。判到终点后前进 40 mm 确保过线，再用接近满占空比（7100/7199）短接制动 150 ms 抱死——低占空比的短接只有一部分时间是制动，其余是滑行。

丢线也有兜底：先直行 150 ms 冲过缝隙 → 慢速左右扫线（1.4 s 换向）→ 3 s 仍找不到就停车。绕行期间丢线流程只暂停、不清状态，避免计时被反复重置。

## 四、可调参数

全部集中在 `Control/config.h`，现场只改这一个文件。

| 宏 | 默认值 | 什么时候改 |
|---|---|---|
| `LOC_CAL` | 1.0 | 里程标定：手推 1000 mm，读第 3 页 `s`（单位 **cm**，推 1 m 应约 100），填 `100/读数`；**这一条必须第一个做** |
| `CM_PER_COUNT_LR` | 0.0077347 | 里程名义系数（π×65mm/1320/2）；不确定就用手推标定 LOC_CAL，别改它 |
| `TRACK_SPEED` | 100 | 巡航速度，先 60 跑顺再往上加；单拍上限约 129 |
| `AVOID_SLOW_CM` / `AVOID_SLOW_SPEED` | 80 / 45 | 减速区距离与区内速度；探头高度变了要重调 |
| `AVOID_TRIGGER_CM` | 45 | 触发距离；提高它会同时放大终点光电门的误触发区，改前先量门柱位置 |
| `START_BLIND_MS` | 600 | 起步还没见到线时最多直行多久；灰度排离车头越远就越要加长 |
| `ULTRA1_IS_LEFT` | 1 | 1 号探头装左侧填 1；装反会朝障碍物转 |
| `AVOID_TURN_ANGLE` / `AVOID_DRIVE_MM` | 60 / 380 | 按赛道宽度与障碍尺寸微调 |
| `STOP_ADVANCE_MM` | 40 | 量车尾投影定；车尾越线就不得分，只有上限没有下限 |
| `FINISH_MIN_TRAVEL_MM` | 4000 | 里程超过它才允许判终点；场地黑区多就往上提 |
| `FINISH_LINE_INDEX` | 1 | 4 m 之后第几次全黑才算终点；场地黑区多就加到 2/3 |
| `FINISH_SLOW_MM` / `STOP_APPROACH_SPEED` | 3500 / 45 | 最后多长里程开始降到 45；**不要为了省时间把 45 调回 60**，否则 2 拍确认的余量只剩 0.16 拍 |
| `FINISH_CONFIRM_CNT` | 2 | 连续几拍全黑才算压线；漏判保持 2，误判加到 3 |
| `ULTRA_BIG_DROP_CM` | 150 | 单次刷新掉得比它多就算毛刺、要下一次刷新确认；调小会更容易挡住假回波，但也会拖慢首次发现 |
| `AVOID_RETRY_ANGLE` / `AVOID_RETRY_MAX` | 12 / 2 | 找线失败时再多转多少度、重试几次 |
| `START_DELAY_S` | 3 | 上电后的放车倒计时；场地紧张就减到 2 |
| `AVOID_CONFIRM_CNT` | 6 | 触发确认的节拍数（6 拍 ≈ 60 ms ≈ 一次测距刷新） |
| `USE_IWDG` | 0 | 比赛时置 1 开看门狗；打断点时置 0 |
| `MOTOR_x_INVERT` / `ENCODER_x_INVERT` | 0/0/1/0 | 换电机或发现正反转不一致时改这里 |

## 五、编译与烧录

1. Keil MDK 5 打开 `Project.uvprojx`，器件已设为 **STM32F103C8**；
2. 需要 **Arm Compiler 5**（工程指定 V5.06 update 5）与 **STM32F1xx_DFP** 器件包；
3. `Project → Rebuild all target files`，应为 `0 Error(s)`；
4. `Options for Target → Debug` 选 ST-Link，Port 用 **SW**，`Flash → Download`；
5. 产物：`Objects\Project.axf`、`Objects\Project.hex`。

> 评估版（MDK-Lite）有 32 KB 代码上限。本工程大致在 25–28 KB 之间（未用 AC5 实测），有余量但不算宽松；若 Rebuild 报 `L6050U`，把 Optimization 从 Level 1 提到 Level 2。

## 六、接线注意

**1. 第二只探头不能直接插进蓝牙座。** 两者引脚顺序不同：

| HC-SR04 | 蓝牙座 |
|---|---|
| VCC | VCC |
| GND | GND |
| Trig（单片机输出） | RXD → PB10 |
| Echo（单片机输入） | TXD → PB11 |

座子上的实际排列以丝印为准，**按名字接，不要按位置接**。照着外形直插会把 Trig 顶到地、把 GND 顶到 VCC，轻则不工作，重则短路或烧引脚。

**2. HC-06 必须物理拔掉。** 模块的 TXD 会一直驱动 PB11，与 Echo 冲突。

**3. 两只探头不要对调。** 2 号（PB10/PB11）两脚都是 5 V 容忍；1 号的 Echo 在 PA2，那是非 5 V 容忍脚。

**4. Trig 是 3.3 V 推挽输出。** HC-SR04 的 Trig 门限标称 TTL（2.0 V），多数模块可触发；若实测"偶尔不触发"，把对应 Trig 脚改成开漏 + 外接 4.7 kΩ 上拉到 5 V（**必须先焊电阻再改代码**）。

## 七、上电自检

第一次通电把车架空、轮子离地，确认这九项再落地：

1. 上电先出现 3 s 倒计时（PLACE CAR），趁这段时间把车摆到起始线，之后保持静止；出现 READY 说明自检完成，两个按键都能翻页；
2. 第 3 页 `sl` / `sr` 随手掌靠近而变化 —— DWT 计时与两路探头都正常；
3. 第 4 页 `F` 显示 **0,0**（前一位超声波故障、后一位陀螺故障）—— 任一为 1 都会禁用对应功能，先排查再落地；
4. 第 4 页 `Q` 两路都应在 0 附近跳变；若一路一直涨到几十、另一路正常，说明那只探头没接上或坏了；
5. 手推车轮，第 1 页 `Speed_L` 与 `Speed_R` 同号、量级接近 —— 编码器极性与方向正确；
6. 手挡 1 号探头 `sl` 变小、挡 2 号 `sr` 变小 —— 两路没接反；
7. 白纸上推车，五路灰度跳变正常，电位器拧到"压线即灭"的临界；
8. 低速跑直道不画龙 —— 转向环与速度环整定到位；
9. 手在 45 cm 处出现，车先减速再绕行，绕完能自己回到线上（注意实际转向点约 36 cm，别拿 45 去卡）；

## 八、目录结构

```
Control/        控制逻辑：config.h（参数）、pid、error（偏差与融合）、element（避障/丢线/终点）、menu
Hardware/       驱动：Motor、Encoder、PWM、sensor、ultrasonic、MPU6050、MyI2C、OLED、Key、Serial
System/         Delay、Timer（10 ms 时基）、myfile.h（统一包含）
User/           main.c、中断向量、test.c（分模块测试，默认注释）
Start/          CMSIS 与启动文件
Library/        STM32F10x 标准外设库
Objects/        Keil 编译产物（已建目录）
Listings/       链接映射文件
```

`User/test.c` 里保留了灰度、编码器、陀螺、电机、PWM、OLED、按键的分模块测试代码，默认全部注释。要用某个测试，先注释掉 `main.c` 的 `main()`，再取消对应测试的注释。
